## Name

Forever Classmate

## Short summary

Compact class-aware companion bars for every WoW Forever class, with learned abilities and racials.

## GitHub description

Class-aware WoW Forever companions for all nine classes: live resources, upkeep, target cues, learned abilities, and racials.

## CurseForge summary

Compact helpers for all nine WoW Forever classes—resources, upkeep, multi-target DoT timers, learned abilities, pets, totems, and racials.

## One-line pitch

Forever Classmate detects your class and shows the compact information that class needs.

## Current release position

Full class bars use a 426-pixel rendered width matching Forever's default desktop Main Hand swing timer. Hunter also offers a 42-pixel red/green range icon, ammo, target context, pet care, family-based beast guidance, and an optional full-bar Inspect button. Every class has a toggleable right-click minimap shortcut to the native Inspect window, including Hunter icon-only mode. Shaman includes readable totem lifetime timers and explicitly marked learned-duration estimates in combat, imbue and shield upkeep, mana, recall, and learned-spec cues. Paladin, Warrior, Rogue, Druid, Mage, Priest, and Warlock add readable resource, grouped upkeep, independently toggleable target/ability, and context-aware active-racial slots driven by the live spellbook and current client state. Warrior, Rogue, Druid, Priest, and Warlock can show observed multi-target DoT timers in slim bars to the right, for the current target and active nameplates. Mage keeps a compact live mana meter and armor readable outside combat without repeating armor art in empty blocks. An active Mana Shield or Ice Barrier shows the client’s total absorb amount and a coverage meter relative to maximum health when available. Native percentage readings keep mana useful when exact resource values are restricted. Unreadable live status stays off every class bar; only confirmed observations and marked cast-based estimates remain. Every enabled bar reveals itself at full opacity on mouseover and resumes its normal fade when the pointer leaves.
