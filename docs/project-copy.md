# Forever Classmate project copy

## Name

Forever Classmate

## Short summary

Compact class-aware companion bars for every WoW Forever class, with learned abilities and racials.

## GitHub description

Class-aware WoW Forever companions for all nine classes: live resources, upkeep, target cues, learned abilities, and racials.

## CurseForge summary

Compact helpers for all nine WoW Forever classes—resources, upkeep, target effects, learned abilities, pets, totems, and racials.

## One-line pitch

Forever Classmate detects your class and shows the compact information that class needs.

## Current release position

Hunter includes range, ammo, target context, pet care, and rare-beast guidance. Shaman includes live totems, imbue and shield upkeep, mana, recall, and learned-spec cues. Paladin, Warrior, Rogue, Druid, Mage, Priest, and Warlock add compact resource, grouped upkeep, independently toggleable target/ability, and context-aware active-racial blocks driven by the live spellbook and current client state.
