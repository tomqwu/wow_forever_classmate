# Forever Classmate project copy

## Name

Forever Classmate

## Short summary

Compact class companions, leveling reminders, and alt/recent mail recipients for WoW Forever.

## GitHub description

WoW Forever companions for all nine classes: resources, upkeep, learned abilities, racials, leveling reminders, and alt/recent mail recipients.

## CurseForge summary

Compact helpers for all nine WoW Forever classes: resources, upkeep, DoT timers, pets, totems, racials, leveling reminders, and alt/recent mail recipients.

## One-line pitch

Forever Classmate detects your class and shows the compact information that class needs.

## Current release position

Full class bars use a 426-pixel rendered width matching Forever's default desktop Main Hand swing timer. Hunter also offers a 42-pixel red/green range icon, ammo with weapon eligibility checks, target context, pet care, family-based beast guidance, and an optional full-bar Inspect button. Every class has a toggleable right-click minimap shortcut to the native Inspect window, including Hunter icon-only mode. Shaman includes readable totem lifetime timers and explicitly marked learned-duration estimates in combat, imbue and shield upkeep, mana, recall, and learned-spec cues. Paladin, Warrior, Rogue, Druid, Mage, Priest, and Warlock add readable resource, grouped upkeep, independently toggleable target/ability, and context-aware active-racial slots driven by the live spellbook and current client state. Warrior, Rogue, Druid, Priest, and Warlock can show observed multi-target DoT timers in slim bars to the right, for the current target and active nameplates. Mage keeps a compact live mana meter and armor readable outside combat without repeating armor art in empty blocks. An active Mana Shield or Ice Barrier shows the client’s total absorb amount and a coverage meter relative to maximum health when available. Native percentage readings keep mana useful when exact resource values are restricted. Unreadable live status stays off every class bar; only confirmed observations and marked cast-based estimates remain. Confirmed missing maintained buffs have independently toggleable pulsing warning borders. An optional sleeping bag reminder appears outside combat at levels 1–59 when the actual Well-Rested buff is confirmed absent, restores full visibility, and clears with any active stack; it never warns at level 60 or from restricted aura data. A separate food reminder prompts levels 1–59 outside combat to eat XP-bonus food when Well Fed is absent. It clears on visible Well Fed and does not measure the hidden XP multiplier; choose food whose tooltip grants +5% XP from kills. Both leveling reminders are independently toggleable, share one aura scan, and preserve the bar size. Every enabled bar reveals itself at full opacity on mouseover and resumes its normal fade when the pointer leaves. English and Simplified Chinese (`zhCN`) interface labels follow the client locale; other locales use English.

The shared mail utility adds paginated Alts and Recent recipients lists beside native Send Mail. Characters are learned by login; alts are filtered to the current realm and faction. History keeps up to 20 successful recipients per sending realm/faction, and each destination preserves the full first name plus surname. Native successful addresses are retained exactly; a hyphen is never assumed to introduce a realm. Click a name to fill the field and right-click to forget it. Its independent class preference works even when the class bar is off. Only names and character identities are saved, without mail contents or amounts.
